# Stage66 LoRa 50% 目标缺口分解报告

## 结论

- LoRa 低分的主因已经不是单纯 New 或聚类；R3 Overall 被 20 个旧类强烈主导，Old 权重约 0.80。
- Stage48 三种子 Old 均值只有 0.2312，New 均值为 0.4770；即使把 New 提到 100%，Overall 理论上也只有约 0.3849。
- 如果保持当前 New 水平，Old 平均需要提高到约 0.5058，Overall 才能到 50%。这比当前 Old 高约 0.2746。
- 当前最好单点是 Stage63 consistency pretrain seed 7，Overall=0.3029；距离 50% 仍差 0.1971。
- 因此继续冲 50 的真正风险点是旧类跨天保持能力，而不是继续把新类 New 从 0.48 小幅推到 0.52。
